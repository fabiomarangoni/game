# Conversor de Tibia Coins

Página para converter **Gold (KK) ⇄ Tibia Coins ⇄ Reais** no Tibia.

## Funcionalidades

- Parâmetros: Valor 250 TC (R$), Valor TC Servidor (Coin), Servidor e Valor Unitário TC (calculado).
- Conversor de Coin (KK → TC → R$) e Conversor de Tibia Coin (TC → KK → R$).
- Tabela de referência de 1 KK a 150 KK.
- Variação Histórica por servidor (Valor 250 TC, Valor TC Servidor e período em dias).
- Guia Histórico com todos os parâmetros armazenados, com filtro por servidor.
- Campos aceitam apenas números, pontos e vírgulas; Enter confirma e recalcula.

## Como usar

Abra o `index.html` no navegador.

Fora do Claude, os últimos valores e o histórico ficam salvos no navegador (localStorage).
Os botões **Buscar** (Rei dos Coins e TibiaTrade) funcionam apenas quando a página é aberta
como artefato no app Claude para desktop; em outros ambientes eles exibem uma mensagem de erro.
